Last updated: 23 November 2026

Pinterest automation app

This is a personal automation tool operated by Aman Kumar (@aman179102). It is used only by the account owner to create, schedule, and manage Pins and boards on the owner's own Pinterest account.

What data is accessed

  • The authenticated Pinterest account's own boards and Pins.
  • Basic profile information needed to identify the authenticated account.
  • Pinterest API credentials and access tokens, which are stored locally by the account owner.

How data is used

  • To create and schedule Pins on the owner's own boards.
  • To read the owner's own board and Pin information for automation and reporting.

Data sharing

No Pinterest data is sold, rented, or shared with third parties. Data is not used for advertising or profiling.

Data storage and retention

Credentials and automation logs are stored locally on the owner's device. They can be deleted at any time by the owner.

Contact

This website

This portfolio is a static website. It does not include user accounts, comments, or a database. If you email me, I will use your message only to reply and will not add you to a mailing list.

Pinterest
