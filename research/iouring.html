Linux io_uring vs epoll I/O Multiplexing in High-Throughput Distributed Cloud Gateways

Author: Aman Kumar (@aman179102)
ORCID: 0009-0002-5219-5949
Scholar: cVhFkv4AAAAJ
DOI: 10.5281/zenodo.24493466
Download Full Paper (PDF) awesome-iouring Repo Technical Deep-Dive
Abstract: Modern cloud-native API gateways under extreme load experience significant tail-latency degradation driven by synchronous kernel transitions and readiness-polling wakeups in legacy epoll architectures. In this research, we evaluate Linux io_uring dual circular ring-buffer semantics (Submission Queue / Completion Queue) against epoll across 100,000 concurrent TCP persistent connections. Our findings demonstrate that io_uring reduces p99 tail latency by 73.4% and eliminates user-kernel context switch overhead via IORING_SETUP_SQPOLL kernel thread submission.
