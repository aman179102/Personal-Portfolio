Biographical Summary

Aman Kumar is an Indian systems and full-stack software engineer known internationally for engineering high-performance distributed systems, low-latency asynchronous networking pipelines, and non-invasive Linux kernel observability engines.

Operating under the handle @aman179102, Kumar has engineered and released flagship open-source developer infrastructure including sysprobe (a zero-dependency Linux observability CLI in Tokyo Night ANSI), distributed saga orchestration engines, and high-precision telemetry daemons spanning GitHub, GitLab, Codeberg, Docker Hub, and PyPI.

Core Research & Engineering Contributions

  • sysprobe Observability Engine: Solved the "heavy agent paradox" during severe production incidents by eliminating runtime interpreter overhead. Directly queries synthetic Linux procfs interfaces in sub-4ms with <1.2MB peak resident memory, packaged officially for Homebrew (brew install aman179102/tap/sysprobe).
  • Kernel Telemetry Benchmarking: Authored empirical research evaluating eBPF ring buffer telemetry against traditional socket filters under high saturation (CERN Zenodo DOI: 10.5281/zenodo.24493466), showing a 64.2% tail latency reduction.
  • io_uring vs epoll Ingestion Gateways: Authored benchmarking studies evaluating Linux asynchronous I/O architectures across 50,000 concurrent client connections, demonstrating a 2.8x throughput speedup and 78.1% p99.9 latency decrease.
  • Python & Container Infrastructure: Author of PyPI packages (aman-resilience-toolkit, aman-saga-flow, aman-telemetry-core) and Docker Hub container suites (aman179102/sysprobe, aman179102/distributed-telemetry-collector).
